# Drakkar ERP — Soft

Рабочий архитектурный прототип покрывает рисковые механизмы Drakkar ERP, а не весь будущий продукт.

Реализованы:

- UC6/UC7: назначение в команду, подтверждение участия и обнаружение конкурентного изменения;
- UC11/UC12: атомарное списание ресурсов и перевод корабля на новый этап, блокировка финала без благословения;
- UC4: предварительный расчёт и атомарная фиксация Вергельда, неизменяемость итогов;
- авторизация с ролевым доступом и серверными сессиями;
- отзыв сессии при выходе: в базе хранится только SHA-256 хеш токена;
- аудит ключевых бизнес-событий.

## Запуск

Нужен Docker с Compose:

```bash
cd soft
cp .env.example .env
docker compose up --build
```

Интерфейс: `http://localhost:8088`.

В runtime два контейнера: один Java-процесс раздаёт React SPA и REST API, второй содержит PostgreSQL. Node.js нужен только на стадии сборки.

### Демо-учётные записи

| Роль | Логин | Пароль |
|---|---|---|
| Ярл | `ragnar` | `raven-2026` |
| Воин | `halvdan` | `shield-2026` |
| Кораблестроитель | `floki` | `oak-2026` |
| Жрец | `godi` | `blot-2026` |

Карточки на экране входа и переключатель в шапке выполняют реальную аутентификацию этими демо-данными. Для публичного развёртывания их нужно заменить.

## Сценарий демонстрации

1. Войти как ярл и назначить свободного жителя в «Экспедицию в Нортумбрию».
2. Переключиться на воина. Кнопка «два ответа одновременно» покажет: первая команда принята, вторая получила `STALE_CREW_ASSIGNMENT`.
3. Войти как кораблестроитель и закрыть два этапа. На финальном этапе сервер потребует Блот.
4. Войти как жрец, подтвердить Блот, затем вернуться к кораблестроителю и закрыть этап.
5. Войти как ярл, указать добычу и потери, получить preview Вергельда и утвердить итоги. Форма станет read-only.
6. Открыть «Журнал событий» и показать след всех операций.

Исходные данные восстанавливаются из «Центра управления» под ролью ярла.

## Проверки

Backend:

```bash
cd soft/backend
mvn test
```

Интеграционные тесты поднимают временный PostgreSQL 16 через Testcontainers.

Frontend:

```bash
cd soft/frontend
npm ci
npm run build
npm audit --omit=dev
```
