# Drakkar ERP — проектные артефакты

Итоговый комплект документов по дисциплине «Методология программной инженерии».

## Состав комплекта

- `Vision.docx` — концепция системы и архитектурно значимые требования.
- `SRS.docx` — спецификация требований к программному обеспечению.
- `Use Case.docx` — общая диаграмма, спецификации и диаграммы прецедентов.
- `Software Development Plan.docx` — план разработки, роли и трудозатраты.
- `Risk List.docx` — реестр проектных рисков.
- `Glossary.docx` — термины и определения проекта.
- `Business Case.docx` — экономическое обоснование проекта.
- `Диаграмма Ганта.xlsx` — календарный план работ и распределение нагрузки.
- `soft/` — прототип Drakkar ERP: frontend, backend, база данных, тесты, Software Architecture Document и ER-схема базы данных.

## Запуск прототипа

Инструкция по локальному запуску находится в `soft/README.md`. Зависимости и результаты локальной сборки в репозиторий не включены: они восстанавливаются стандартными командами проекта.

Файлы в этой директории являются каноническими версиями для публикации в репозитории.
